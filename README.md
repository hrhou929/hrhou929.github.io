# Haoran Hou — Personal Website

[hrhou929.github.io](https://hrhou929.github.io/)

This repository contains the source code for my personal website, featuring my research, professional experience, education, and interests.

I am an undergraduate in Statistics and Data Science at The Chinese University of Hong Kong. My interests include agent systems, LLM and agent evaluation, and multimodal AI.

## Website Content

- **Home:** Biography, research interests, selected research, and recent updates.
- **Experience:** Research experience, internships, education, and technical skills.
- **Beyond:** Personal interests outside academic and professional work.
- **CV:** A web-based curriculum vitae with print and PDF export support through the browser.

## Repository Structure

| File | Purpose |
| --- | --- |
| `index.html` | Main website, including styles and navigation |
| `cv.html` | Printable curriculum vitae |
| `assets/` | Site icons and other visual assets |
| `.nojekyll` | Disables Jekyll processing for static hosting |

## Local Preview

The website uses HTML, CSS, and JavaScript without external dependencies or a build step. Open `index.html` in a browser to preview it locally.

## Deployment

The site is hosted on GitHub Pages. The publishing source is the root directory of the `main` branch. Updates to the website are maintained directly in this repository.
